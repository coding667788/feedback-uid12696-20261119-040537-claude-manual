为事故调查实现本地数字取证保全包核验器。每件合成证物由采集记录固定 SHA-256、租户、保管主体和采集时刻；交接记录绑定前一交接摘要、交出和接收双方、双方模拟签名、各自授权种类及签署时刻。不接触真实取证数据。交接候选可乱序、重复和分叉。时间戳来自可不一致的机构时钟，每个机构的本地时钟在整包内只能选一个整数秒偏移，偏移取自给定的闭区间。全局时刻等于本地时刻加机构偏移，须满足双方签名先于入保全库、交接时间非递减。锚点只接受已登记的采集与保全检查点。

保全包给若干证物和截止时刻，每件证物都需找到一条可定时交接链，且同一个物理交接凭单最多配给一件证物；该凭单可绑定多个候选证物的承接记录，各记录均须对上确切前序摘要；至少两类不同机构的独立人员须分别对整个包中所有证物给出覆盖见证，一个人员最多承担一类。对最多 8 件证物和 60 条候选记录求一个全局合法解，先最少不同出库交接项数，后按证物 ID 和交接 ID 序列比较，然后选字典序最小的可行全局时刻。输出每项回链和实际时刻，若无解区分单件不可校准、全局交接占用冲突及见证不足。

固定测试局部最短链占用其他证物唯一交接、一条链表面时间反转却可校准、校准区间各自可行但组合冲突、重复见证人和伪造同摘要的新分叉。小输入用独立组合穷举及手工时间见证核对，给无解例与并列解。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
